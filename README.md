# Aura Workshop — demo

Copia **terminada a medias a propósito**: podés ver y correr la cara del producto si en el taller no llegamos al final.

No es el sistema completo de Aura (no trae el pipeline de producción, ni credenciales, ni bases reales).

```
git clone https://github.com/CristinaChaconSanta/aura-workshop-demo.git
cd aura-workshop-demo/web
npm install
npm run dev
```

Guía: `workshop/guia-asistentes.md`.  
Corpus: `corpus/`.
